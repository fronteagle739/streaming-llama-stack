# Native source parity checkpoint

The JSON records real measured native-engine comparisons and their limits.
Windows compares 384 full-vocabulary vectors and every greedy choice with a
retained private zero-bias control. Mac compares a complete32-token state with
an independently compiled private core/Metal build under identical settings.
The Mac source texts match after CRLF normalization only.

The Windows control passed with no increase in system page-output/page-write
counters. This does not certify all-mode residency. A separate OS test verifies
every page of the full4,536,143,872-byte carry bank is anonymous and locked,
plus release and failed-allocation cleanup. The old pageable policy fails that
test. Producer integration and the two-machine walkthrough are still pending.

No model weights, raw states, private inputs or machine-specific logs are committed.
